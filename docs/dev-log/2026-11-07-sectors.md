# 2026-11-06 ~ 11-07 실습 기록: 해외 개별주 섹터와 GICS 분류

LIVE 계좌의 해외 개별주에 섹터를 붙이고, 대시보드에 섹터별 구성을 보여 준 뒤, 섹터 이름을 GICS 11개 섹터(한글·영문)로 바꿨습니다. 계좌번호, 보유 종목, 금액, 키 값은 이 문서에 적지 않습니다. 아래 종목 예시는 공개 종목의 KIS 업종 확인용입니다.

## 1. 출발점

- KIS 잔고 API는 섹터를 주지 않음. 섹터는 사용자가 `classifications.json`에 직접 적은 종목만 있었음
- 대시보드는 자산 구성 도넛만 있었음

## 3. 결정한 것

| 질문 | 선택 | 이유 |
| --- | --- | --- |
| 업종 코드 → 이름 | KIS 업종별코드조회 API | 코드로 이름을 추측하지 않기 위해. 공개 데이터라 거래소별 하루 한 번 받아 모든 사용자가 공유(디스크 캐시) |
| 화면에 보일 분류 | GICS 11개 섹터 | KIS 업종은 40여 개라 도넛이 너무 잘게 쪼개짐. 운영자가 GICS 9개 섹터 목록을 주었고, 남는 업종(전기·가스·공익사업, 리츠)이 미분류가 되지 않게 유틸리티·부동산을 더함 |
| 묶는 기준 | 업종명 | 코드는 거래소마다 다를 수 있으나 업종명은 같음. NAS·NYS 표는 동일함을 확인 |
| 모르는 업종명 | 섹터 정보 없음 | 추측하지 않음 |
| 우선순위 | `classifications.json` > 종목 예외 > KIS 업종 | 사용자 지정이 가장 우선 |

## 4. 확인하며 발견한 것

### KIS 업종과 GICS가 다른 종목

운영자가 준 대표 종목을 마스터 파일에서 확인했습니다. 대부분 업종을 묶으면 GICS와 같았지만 몇 개는 달랐습니다.

- V·MA·PYPL: KIS는 `720 인터넷소프트웨어 및 IT서비스`, GICS는 금융
- WMT·LIN: 업종분류코드가 `000`(없음)
- AMZN·HD·BKNG는 `380 도/소매`라 임의소비재로 맞음. COST는 `430 음식료 도매`라 필수소비재로 맞음
- GOOGL·META·NFLX·DIS는 `370 미디어`라 커뮤니케이션 서비스로 맞음

다른 다섯 종목은 `app/integrations/kis/gics.py`의 `SYMBOL_SECTOR`에서 미국 상장 종목에 한해 바로잡습니다. 그 밖의 종목은 `classifications.json`으로 지정합니다.
