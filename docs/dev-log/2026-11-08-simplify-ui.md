# 2026-11-08 실습 기록: 피드백 반영, 화면을 조금 쉽게

"기능이 너무 많고 화면에 보이는 게 많아서 접근이 어렵다"는 피드백을 받고 화면을 단순하게 바꿨습니다. 기능을 지운 것보다는 덜 중요한 것을 뒤로 숨기고, 의미 없는 정보를 치운 쪽에 가깝습니다. 계좌번호, 보유 종목, 금액, 키 값은 이 문서에 적지 않습니다.

## 1. 출발점: 무엇이 복잡했나

| 위치 | 문제 |
| --- | --- |
| 메뉴 | 6개. 모바일 하단 탭은 글씨가 10.5px. 그중 AI 리포트는 "아직 제공되지 않습니다"뿐인 빈 페이지 |
| 헤더 | MOCK/LIVE 토글이 항상 보임. 개발자에게만 익숙한 말 |
| 모든 화면 상단 | 출처 막대에 LIVE 표시·기준 시각·조회 시각·환율·갱신 버튼 5개 |
| 모든 화면 하단 | "계산 전제" 목록이 항상 펼쳐져 있음 |
| 대시보드 | 블록 약 10개. 총자산을 카드 4개로 다시 쪼갬. 총자산 변화는 기록이 없어 대부분 빈 상태. 자산 구성·통화 구성은 한 칸(100%)짜리 |
| 분석 | 카드 8개. ETF가 없는데 ETF 중복 카드가 큼. "계산하지 않은 지표"가 카드 하나. 인사이트·자산군·통화는 대시보드와 중복 |

## 2. 바꾼 것

| 항목 | 전 | 후 |
| --- | --- | --- |
| 메뉴 | 대시보드·보유 종목·분석·AI 리포트·시뮬레이터·설정 | 홈·보유 종목·분석·시뮬레이터. 설정은 헤더 오른쪽 계정(톱니바퀴) 버튼으로 |
| 데이터 모드 | 헤더 MOCK/LIVE 토글 | 로그인 시 한국투자증권 키가 있으면 실제 계좌, 없으면 체험 데이터. 키 등록·삭제 시에도 자동 전환. 직접 바꾸려면 설정 → 보기 모드(체험 / 실제 계좌) |
| 출처 표시 | 5개 항목 한 줄 | "실제 계좌 · 시각 기준 · 자세히 · ↻". 조회 시각·환율은 "자세히"로 펼침 |
| 홈 | 약 10개 블록 | 총자산 카드(손익·수익률·원금·종목 수 포함), 섹터 도넛, 비중 큰 종목 5개(+전체 보기), 인사이트 2개(+더 보기). 총자산 변화는 기록이 2개 이상일 때만 |
| 분석 | 카드 8개 | 섹터·종목 집중도가 위. 한 가지뿐인 분포(국가·자산군·통화)와 해당 없는 ETF 중복 카드는 숨기고 "생략한 항목"을 한 줄로 알림. 중복 인사이트 제거 |
| 계산 전제 | 항상 펼침 | "계산 기준 보기"로 접음. "계산하지 않은 지표"도 그 안으로 |
| 설정 | 카드 7개 나열 | 계정·보기 모드·키·자산 기록·시뮬레이션 기록만 보이고, 저장된 설정·서버 연결 상태는 "고급 설정"으로 접음 |

커밋: `cb9c2d0` (웹 화면만 변경, API·계산 로직은 그대로)

## 3. 결정한 것

| 질문 | 선택 | 이유 |
| --- | --- | --- |
| 정보를 지울지 숨길지 | 대부분 숨김(접기·조건부 표시) | 계산 근거와 출처는 투명하게 남겨야 함. 다만 처음 보는 화면에는 필요 없음 |
| 한 칸 100% 차트 | 숨기되 생략 사실은 표시 | 정보가 없는 차트지만, 말없이 사라지면 오류로 보일 수 있음 |
| MOCK/LIVE 결정 | 키 등록 여부로 자동 | 사용자가 모드 개념을 몰라도 되게. 기존 "로그인 시 기본 데이터 모드" 설정은 화면에서 뺌(저장값·API는 유지) |
| AI 리포트 | 메뉴에서 제외, 주소는 유지 | 빈 페이지를 메뉴에 두지 않음. Phase 5에서 복귀 |
| 용어 | MOCK/LIVE → 체험/실제 계좌 | 일반 사용자가 읽을 수 있는 말로 |
